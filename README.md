# Roomify

Roomify is a browser-based bedroom design website built with React, Three.js, and Vite. It runs as a normal website in a desktop or mobile browser; it is not a native mobile app.

## Run locally

```sh
pnpm install
pnpm dev
```

Open the local URL printed by Vite. To create a production build, run `pnpm build`.

Designs are saved in the browser's local storage when **Save design** is selected. Furniture, finishes, room style, and lighting are editable in the workspace.
